The Functions service allows you to create custom behaviour that can be triggered by any supported AACSearch system events or by a predefined schedule.

AACSearch Cloud Functions lets you automatically run backend code in response to events triggered by AACSearch or by setting it to be executed in a predefined schedule. Your code is stored in a secure way on your AACSearch instance and is executed in an isolated environment.

You can learn more by following our [Cloud Functions tutorial](/docs/products/functions).
