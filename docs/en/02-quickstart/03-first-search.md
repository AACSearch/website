## Работа с фильтрами

Фильтры позволяют уточнить результаты поиска.

### Добавление фильтров

Нажмите **"Фильтры"** под поисковой строкой:

```
┌─────────────────────────────────────────┐
│  Фильтры                                │
├─────────────────────────────────────────┤
│                                         │
│ Price (float):                          │
│ [ ] < 100                               │
│ [✓] 100 - 500                           │
│ [✓] 500 - 1000                          │
│ [ ] > 1000                              │
│                                         │
│ Category (string):                      │
│ [✓] Электроника         (12)            │
│ [ ] Аксессуары          (3)             │
│ [ ] Периферия           (5)             │
│                                         │
│ In Stock (bool):                        │
│ [✓] В наличии                           │
│ [ ] Нет в наличии                       │
│                                         │
│ [Применить фильтры]  [Сбросить]         │
└─────────────────────────────────────────┘
```

### Результат с фильтрами

```

│ 🔍 ноутбук                                    [Искать]  │

│                                                         │

└─────────────────────────────────────────────────────────┘
```

### Фильтры через query string

**Формат:** `field:operator value`

**Примеры:**

```
Цена больше 500:
price:>500

Цена в диапазоне:
price:[100..1000]

Категория:
category:Электроника

Булево значение:
in_stock:true

Множественные условия (AND):
price:>500 && category:Электроника

Множественные условия (OR):
category:Электроника || category:Аксессуары

Комбинация:
(price:>500 && category:Электроника) || in_stock:false
```

### Операторы фильтрации

```
┌──────────────┬────────────────────────────────────────┐
│ Оператор     │ Описание                               │
├──────────────┼────────────────────────────────────────┤
│ :            │ Равно                                  │
│ :=           │ Строгое равно (для массивов)           │
│ :!=          │ Не равно                               │
│ :>           │ Больше                                 │
│ :>=          │ Больше или равно                       │
│ :<           │ Меньше                                 │
│ :<=          │ Меньше или равно                       │
│ :[min..max]  │ Диапазон (включая границы)             │
│ :!=[x, y]    │ Не входит в список                     │
└──────────────┴────────────────────────────────────────┘
```

### Range фасеты (диапазоны)

Для числовых полей можно настроить диапазоны:

```json
{
  "facet_by": "price",
  "facet_query": "price:[0..100], price:[100..500], price:[500..1000], price:[1000..999999]"
}
```

Результат:
```
Price Range:
□ $0 - $100       (5 товаров)
□ $100 - $500     (18 товаров)
□ $500 - $1,000   (25 товаров)
□ > $1,000        (12 товаров)
```

## Сортировка результатов

### Варианты сортировки

```
┌─────────────────────────────────────────┐
│  Сортировать по:                        │
├─────────────────────────────────────────┤
│ (•) Релевантности (_text_match)         │
│ ( ) Цене (возрастание)                  │
│ ( ) Цене (убывание)                     │
│ ( ) Названию (A-Z)                      │
│ ( ) Названию (Z-A)                      │
│ ( ) Дате добавления (новые)             │
│ ( ) Дате добавления (старые)            │
│                                         │
│ [Применить]                             │
└─────────────────────────────────────────┘
```

### Множественная сортировка

```
Сортировать по:
1. [Релевантности ▼]  [Убывание ▼]
2. [Цене ▼]           [Возрастание ▼]
3. [+ Добавить уровень]
```

**Логика:**
1. Сначала по релевантности
2. При одинаковой релевантности — по цене
3. При одинаковой цене — далее...

### Сортировка через API

```bash
# По релевантности (по умолчанию)
?sort_by=_text_match:desc

# По цене (возрастание)
?sort_by=price:asc

# По цене (убывание)
?sort_by=price:desc

# Множественная сортировка
?sort_by=_text_match:desc,price:asc
```

## Настройка релевантности

Тонкая настройка качества результатов поиска.

### Вес полей

Определяет важность полей для релевантности.

```
┌─────────────────────────────────────────┐
│  Настройка весов полей                  │
├─────────────────────────────────────────┤
│                                         │
│ Поля для поиска:                        │
│                                         │
│ title                                   │
│ Вес: [████████████] 10                  │
│                                         │
│ description                             │
│ Вес: [█████░░░░░░░] 5                   │
│                                         │
│ tags                                    │
│ Вес: [███░░░░░░░░░] 3                   │
│                                         │
│ [Применить] [Сбросить по умолчанию]     │
└─────────────────────────────────────────┘
```

**Эффект:**
- Совпадение в `title` → max релевантность
- Совпадение в `description` → средняя
- Совпадение в `tags` → низкая

### Prefix matching

Поиск по началу слова.

```

│ (Множитель релевантности)               │
│                                         │

└─────────────────────────────────────────┘
```

### Typo tolerance (исправление опечаток)

```
┌─────────────────────────────────────────┐
```

### Синонимы

Расширьте поиск синонимами.

```
┌─────────────────────────────────────────┐
│  Управление синонимами                  │
├─────────────────────────────────────────┤
│                                         │
│ [+ Добавить группу синонимов]           │
│                                         │
│ ┌─────────────────────────────────────┐ │
│ │ Группа #1                           │ │
│ │ laptop = ноутбук = лаптоп           │ │
│ │ [Edit] [Delete]                     │ │
│ └─────────────────────────────────────┘ │
│                                         │
│ ┌─────────────────────────────────────┐ │
│ │ Группа #2                           │ │
│ │ smartphone = смартфон = телефон     │ │
│ │ [Edit] [Delete]                     │ │
│ └─────────────────────────────────────┘ │
│                                         │
└─────────────────────────────────────────┘
```

**Эффект:** Запрос "laptop" найдет также "ноутбук" и "лаптоп"

### Boosting (повышение релевантности)

```json
{
  "q": "laptop",
  "query_by": "title,description",
  "filter_by": "category:Electronics",
  "sort_by": "_text_match:desc",
  "prioritize_exact_match": true,
  "boost_by": {
    "field": "rating",
    "factor": 1.5
  }
}
```

**Логика:** Товары с высоким рейтингом поднимаются выше

## Поиск через API

### Базовый GET запрос

```bash
curl -X GET \
  'https://api.aacsearch.com/v1/collections/products/search?q=ноутбук&per_page=10' \
  -H 'X-API-Key: YOUR_API_KEY' \
  -H 'X-Tenant-ID: YOUR_TENANT_ID'
```

**Ответ:**
```json
{
  "found": 15,
  "out_of": 1000,
  "page": 1,
  "per_page": 10,
  "search_time_ms": 12,
  "hits": [
    {
      "document": {
        "id": "1",
        "title": "Ноутбук HP ProBook 450",
        "description": "Профессиональный ноутбук для бизнеса",
        "price": 899.99,
        "category": "Электроника"
      },
      "highlights": {
        "title": {
          "snippet": "<mark>Ноутбук</mark> HP ProBook 450",
          "matched_tokens": ["Ноутбук"]
        }
      },
      "text_match": 10500000000
    }
  ],
  "facet_counts": []
}
```

### POST запрос с фильтрами

```bash
curl -X POST \
  'https://api.aacsearch.com/v1/collections/products/search' \
  -H 'X-API-Key: YOUR_API_KEY' \
  -H 'X-Tenant-ID: YOUR_TENANT_ID' \
  -H 'Content-Type: application/json' \
  -d '{
    "q": "ноутбук",
    "query_by": "title,description",
    "filter_by": "price:[500..1500] && category:Электроника",
    "sort_by": "price:asc",
    "facet_by": "category,brand",
    "max_facet_values": 10,
    "per_page": 20,
    "page": 1,
    "highlight_full_fields": "title,description"
  }'
```

### Параметры поиска

```
┌────────────────────┬─────────────────────────────────────┐
│ Параметр           │ Описание                            │
├────────────────────┼─────────────────────────────────────┤
│ q                  │ Поисковый запрос                    │
│ query_by           │ Поля для поиска (через запятую)     │
│ filter_by          │ Условия фильтрации                  │
│ sort_by            │ Сортировка                          │
│ facet_by           │ Поля для фасетов                    │
│ max_facet_values   │ Макс. значений фасета (default: 10) │
│ per_page           │ Результатов на странице (max: 250)  │
│ page               │ Номер страницы (начинается с 1)     │
│ highlight_fields   │ Поля для подсветки                  │
│ snippet_threshold  │ Длина snippet (default: 30)         │
│ num_typos          │ Макс. опечаток (0, 1, 2)            │
│ prefix             │ Prefix matching (true/false)        │
│ infix              │ Infix matching (off/always/fallback)│
│ drop_tokens_threshold│ Убирать слова для результатов     │
└────────────────────┴─────────────────────────────────────┘
```

## Troubleshooting

### Нет результатов

**Проверьте:**
1. Документы загружены: Меню → Коллекции → products
2. Поля проиндексированы: Schema → проверьте `index: true`
3. Опечатки: попробуйте точное совпадение
4. Язык: проверьте стемминг для вашего языка

### Неправильная релевантность

**Оптимизация:**
1. Увеличьте вес важных полей (title → 10)
2. Используйте `prioritize_exact_match: true`
3. Настройте синонимы
4. Проверьте typo tolerance (слишком много ошибок?)

### Медленный поиск

**Причины:**
- Слишком много фасетов
- Большой `per_page` (>100)
- Сложные фильтры с OR

**Решения:**
- Используйте кэширование
- Ограничьте facet_by
- Оптимизируйте фильтры
- Используйте индексы для сортировки

## FAQ

### Сколько результатов можно получить за один запрос?

- **Максимум per_page:** 250
- **Рекомендуется:** 10-20 для UI, 100 для API

Для большего количества используйте пагинацию:
```
page=1&per_page=100  → документы 1-100
page=2&per_page=100  → документы 101-200
```

### Можно ли искать по всем коллекциям сразу?

Да! Используйте **Multi-Search**:

```bash
POST /multi_search
{
  "searches": [
    {"collection": "products", "q": "laptop"},
    {"collection": "articles", "q": "laptop"},
    {"collection": "reviews", "q": "laptop"}
  ]
}
```

### Как работает подсветка (highlighting)?

Платформа автоматически оборачивает найденные слова в `<mark>` теги:

```html
"Ноутбук HP ProBook"
→ "<mark>Ноутбук</mark> HP ProBook"
```

Настройка:
```json
{
  "highlight_fields": "title,description",
  "highlight_full_fields": "title",
  "highlight_affix_num_tokens": 8
}
```

### Как искать точную фразу?

Используйте кавычки:
```
q="HP ProBook 450"
```

Найдет только точное совпадение, а не отдельные слова.
